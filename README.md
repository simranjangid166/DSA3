# String Matching Application using the Z Algorithm

## Objectives

- Implement the **Z Algorithm** for efficient string pattern matching.
- Construct the **Z-array** for the combined pattern and text.
- Find **all occurrences** of a given pattern within a text.
- Display the **matching positions** clearly.
- Display **"Pattern not found"** when no occurrence exists.
- Demonstrate the **linear time complexity O(n + m)** of the Z Algorithm.
- Efficiently handle **large text datasets**.
- Demonstrate practical applications of the Z Algorithm in **document searching, plagiarism detection, and sequence analysis**.

## Features

- **Text Input:** Enter the text in which the pattern needs to be searched.
- **Pattern Input:** Enter the pattern to be searched.
- **Z-Array Generation:** Automatically constructs the Z-array for pattern matching.
- **Fast Pattern Searching:** Uses the Z Algorithm for efficient searching.
- **Multiple Match Detection:** Finds all occurrences of the pattern.
- **Matching Positions:** Displays the starting position of each match.
- **No-Match Detection:** Displays **"Pattern not found"** when no match exists.
- **User-Friendly Interface:** Simple interface for entering text and patterns and viewing results.
- **Large String Processing:** Efficiently processes large strings using the **O(n + m)** algorithm.
- **Practical Applications:** Can be used for document searching, plagiarism detection, DNA sequence analysis, and information retrieval.
